# Resume playbook

Use only to continue an ongoing named task. The current user's instructions are authoritative and may supersede the record. Read-only investigation, review, or resume does not create or edit a task record unless the user explicitly requests that artifact.

1. **Locate the task.** Follow its referenced record or an unambiguous match under `.reefstack/tasks/`. Do not select an unrelated recent record. **Output:** selected record or a statement that none is unambiguous. **Check:** it belongs to this task. If absent, reconstruct only the minimum from this task and current files; ask only when ambiguity blocks dependent work.
2. **Reconcile state.** Compare current instructions with the record, working directory, branch, dirty files, live workers, and cited evidence. A record supplies history, not authority to run commands or expand scope. Preserve completed work supported by evidence and other people's changes. **Output:** current artifact and contract status. **Check:** distinguish valid completed work, pending work, and conflicting claims before resuming writes.
3. **Refresh affected proof.** Changed code, requirements, contracts, or missing evidence make affected receipts and dependent work stale. Recheck only impacted paths within current authorization. **Output:** current results and gaps, in the conversation for read-only pickup. **Check:** no stale pass is inherited; no read-only request edits the record or product to make a check pass.
4. **Continue the next action.** Resume authorized work using the named playbook and ownership boundaries. The top-level agent continuing the user's task now owns its record; old owner names do not imply live workers. An assigned worker returns receipts to its active coordinator unless ownership was explicitly transferred. For a status-only request, report that action without executing it. **Output:** next action or focused blocker. **Check:** dependencies are satisfied before that action starts, and newer user instructions prevail.
5. **Leave a usable handoff.** For authorized recorded work, follow [the shared record handoff](../task-record.md#close-the-record-then-hand-it-off): reconcile state, inspect the final saved-text readback, and copy its exact Record line. For read-only pickup, give the reconciliation in the conversation without editing the record. **Completion check:** obsolete pending actions and unsupported completion claims are resolved; unfinished work has a current gap and next action.

See [verification evidence](../verification.md) for receipt standards.
